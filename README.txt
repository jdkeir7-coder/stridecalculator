STRIDE CALCULATOR — NAMED HTML PAGES

These FOUR HTML pages sit directly in your GitHub Pages repository root:

index.html            Pace Conversion Tool (homepage)
calculator.html       Split Calculator
about-faq.html        About & FAQ
pacing-guides.html    Pacing Guides library AND complete 800m guide on the SAME page

The interactive 800m split explorer and all of its CSS/JavaScript are embedded
inside pacing-guides.html. There is NO separate 800m-pacing.html and NO guides/index.html.

Also included: sitemap.xml, robots.txt.

To publish:
1. Extract the ZIP.
2. Upload the extracted files to the root of your GitHub repository.
3. Commit and wait for GitHub Pages to deploy.
4. Remove the OLD 'guides/' directory from the GitHub repository if it exists,
   to avoid keeping obsolete duplicated guide URLs online.
5. Check https://stridecalculator.com/pacing-guides.html and use the
   'Read the 800m guide' link to jump down to the article on that same page.
6. Submit https://stridecalculator.com/sitemap.xml in Search Console.

Note: Combining the library and 800m article in one HTML page meets this request,
but a dedicated URL per article usually helps search engines distinguish article
topics once there are enough finished guides to justify separate pages.
